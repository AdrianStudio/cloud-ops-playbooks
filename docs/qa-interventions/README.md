# QA Interventions

Every artifact in this repository is generated by an LLM and must pass
deterministic reviewers before a pull request is opened. No LLM takes part in
the review. Each file in this folder records one case where a reviewer
rejected an attempt and forced a rewrite. File names start with the date, so
the listing reads in chronological order.

| Reviewer | What it rejects |
|---|---|
| QA | Syntax errors (Python AST, `tofu validate`, PowerShell parser), silent fallbacks, broad or empty exception handlers, narrated or placeholder comments |
| README reviewer | Missing sections, undocumented environment variables or inputs, missing usage commands, filler wording |
| Security Gate | Hardcoded secrets, destructive commands, disabled security controls |
| Schema validation | Responses that do not match the required output structure |
